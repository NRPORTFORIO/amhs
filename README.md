# 📂 組み込みファームウェア開発 ＆ データ解析 ポートフォリオ

C言語を用いた組み込み制御アルゴリズム（入力制御・センサー処理・モーター制御）および、Pythonを用いた稼働ログのデータ解析をシミュレートした総合プロジェクトです。
実機（マイコン）がない環境でも、ロジックの正確性と品質保証のプロセスを検証できる構成にしています。

---

## 🛠️ 実装した主要機能と技術的アピールポイント

### 1. 高級キーボード・操作盤向け 入力制御アルゴリズム
* **チャタリング防止処理 (`debounce.c`)**
  * 物理ボタン特有の電気的ノイズを`struct`（構造体）を用いたカプセル化処理で綺麗に除去します。
* **動性感度調整 ＆ ヒステリシス制御 (`sensor_control.c`)**
  * 境界値での判定のバタつきを防ぐ「ヒステリシス制御」を実装。列挙型（`enum`）を活用し、動的なしきい値切り替えに対応しています。

### 2. 半導体搬送装置（AMHS）向け 制御＆解析システム
* **過速度・障害物検知 ＆ 台形加減速制御 (`motor_control.c`)**
  * 精密機器を安全に運ぶための滑らかな加減速ロジックです。危険を察知した瞬間に最優先でシステムを止める「フェイルセーフ（安全装置）」を組み込んでいます。
* **運行ログの自動データ解析 (`analyze_log.py`)**
  * C言語が吐き出したCSVログをPython（pandas）で読み込み、最高速度や総走行距離の算出、異常停止の予兆検知など「品質保証・稼働監視の自動化」をシミュレートしています。

---

## 📂 構成ファイル
* `debounce.c`: チャタリング防止ロジック
* `sensor_control.c`: アナログ値判定・ヒステリシス制御
* `motor_control.c`: 搬送ロボットの加減速・安全制御
* `analyze_log.py`: Pythonによる運行ログ解析スクリプト
